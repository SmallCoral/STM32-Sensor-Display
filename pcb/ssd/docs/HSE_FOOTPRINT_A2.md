# A2 外部晶振与封装修订

本版添加 24MHz HSE 电路，将 MCU 封装改为 ST 数据手册示例焊盘，并将圆屏铜焊盘减小至 1.8mm。封装库和 PCB 内实际焊盘均已更新，原有 57 个器件的坐标及旋转角度保留；没有添加 PCB 走线。

## MCU 焊盘与脚号

U401 绑定 **`SSD:STM32C562CET6_LQFP48_ST`**。依据 [DS14927 Rev2](reference/STM32C562xx_DS14927_Rev2.pdf) 第108～110页、表76与图42：

| 项目 | A1 通用 KiCad 焊盘 | A2 ST 示例焊盘 |
| --- | --- | --- |
| 本体尺寸 | 7×7mm | 7×7mm |
| 焊盘数量 / 中心脚距 | 48 / 0.50mm | 48 / 0.50mm |
| 单个焊盘长×宽 | 1.475×0.30mm | **1.20×0.30mm** |
| 相对两排中心距离 | 8.325mm | **8.50mm** |
| 焊盘最外沿跨度 | 9.80mm | **9.70mm** |
| 焊盘最内沿间距 | 6.85mm | **7.30mm** |
| 中央散热焊盘 | 无 | 无 |

前版使用通用 IPC 焊盘，不能仅凭其与 ST 示例尺寸不同就判定封装类型错误；本版按用户要求统一采用 ST 图42的尺寸，便于逐项复核。ST 标注的 **9mm 是芯片引脚外跨**，9.70mm 是推荐铜焊盘外跨，两者含义不同。

顶视图中，1～12 脚沿左侧向下，13～24 沿下侧向右，25～36 沿右侧向上，37～48 沿上侧向左。编号与 DS14927 图5一致；图42将 1 脚画在下侧，整幅图旋转90°后即可对照，不需要镜像脚号。

MCU 和新增晶振的 STEP 模型保存在 `libraries/SSD.3dshapes/`，通过 `${KIPRJMOD}` 相对工程绑定。模型用于外形检查；电气连接以符号脚号、铜焊盘和网表核对为准。模型取自 KiCad 10.0.6 对应封装库。

## 24MHz 外部晶振

此前采用 HSI / CRS 是因为 C562 的 ROM USB DFU 不要求外部晶振。现已加入应用程序可使用的 **24MHz HSE**；ROM DFU 仍按 AN2606 第11章表23使用其内部时钟，不会因为安装晶振就自动改用 HSE。

| 器件 | 参数 / 连接 |
| --- | --- |
| Y401 | Abracon **ABM8-24.000MHZ-10-D2Y-T**；24MHz、CL=10pF、基频、−40～85℃、频差±20ppm、稳定度±30ppm |
| U401-5 | PH0-OSC_IN，接 Y401-3 与 C408 |
| U401-6 | PH1-OSC_OUT，经 R401 接 Y401-1 与 C407 |
| Y401-2 / 4 | 外壳接 GND |
| C407 / C408 | 初值 **12pF、C0G、0603**，建议±0.5pF、≥25V |
| R401 | 初装 **0Ω、0603**，位于 OSC_OUT 至晶体之间，用于驱动功率调试 |

晶振依据 [Abracon ABM8 2020-07-29 数据手册](reference/Abracon_ABM8_Rev20200729.pdf) 选型：24MHz 时 ESR≤50Ω，C0≤3pF，最大驱动功率100µW。负载电容按 `CL=C407×C408/(C407+C408)+Cstray` 估算，12pF / 12pF 配合约4pF总杂散时得到10pF；4pF是设计估计，最终数值需在实际 PCB 上确认。

按最坏 ESR 与 C0 计算，晶体临界跨导约为 `4×50×(2π×24MHz)²×(3pF+10pF)² = 0.769mA/V`，低于 DS14927 表35给出的1.5mA/V最大允许晶体临界跨导。最终仍需验证冷启动、温度范围、频偏和驱动功率；需要时调整 R401 及负载电容。芯片已内置反馈电阻，不额外并联1MΩ。

Y401 采用按厂商第2页推荐图制作的 **`SSD:Abracon_ABM8_3.2x2.5mm`**：四个1.30×1.05mm焊盘，中心距2.30×1.75mm，1/3为晶体端、2/4为外壳地。不能将同尺寸的四脚有源振荡器当作替代品。

固件需要启用 HSE 晶体模式，等待就绪后再选择相应系统时钟 / PSI 参考；安装晶振本身不会更改时钟寄存器。本次没有修改旧固件。LSE 32.768kHz 未安装，PC13 按键与 LSE 的勘误约束保持原说明。

## 圆屏焊盘

DS201 的16个铜焊盘从 **2.0mm 改为1.8mm**，1脚仍以方形识别，其余为圆形。钻孔维持1.0mm，标称单边焊环为0.40mm；中心针距2.54mm、两排间距35.08mm和编号均保持不变。

原屏幕资料未给出可确认的针径标称值，所以这次只减小铜焊盘。实际插装间隙仍需拿屏幕核对，见更新后的 [圆屏 1:1 对位图](../review/display_footprint_1to1.pdf)。

## 验证与打开方式

当前61个器件，24个电阻、19个电容均为0603。原理图 ERC、网表、48脚映射、封装几何及 PCB 同步检查的结果保存在 `review/`。PCB 尚无板框和走线；原 USB-C 封装的4项孔到铜间距提示仍保留，未调整规则。

修改前备份见 [before_hse_footprint_revision.zip](../review/before_hse_footprint_revision.zip)。如果 KiCad 编辑器仍显示旧封装，应关闭旧窗口并重新打开已更新工程，避免将内存中的旧版再次保存覆盖。
