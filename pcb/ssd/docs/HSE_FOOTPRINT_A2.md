# A2 晶振与封装记录

A2 增加了 24MHz HSE 电路，MCU 封装改用 ST 数据手册中的示例焊盘，圆屏铜焊盘直径调整为 1.8mm。后续布局版本又删除了晶振串联电阻 R401，晶体两端现直接连接 PH0 / PH1。

## MCU 焊盘与脚号

U401 绑定 **`SSD:STM32C562CET6_LQFP48_ST`**。依据 [DS14927 Rev2](reference/STM32C562xx_DS14927_Rev2.pdf) 第108～110页、表76与图42：

| 项目 | A1 通用 KiCad 焊盘 | A2 ST 示例焊盘 |
| --- | --- | --- |
| 本体尺寸 | 7×7mm | 7×7mm |
| 焊盘数量 / 中心脚距 | 48 / 0.50mm | 48 / 0.50mm |
| 单个焊盘长×宽 | 1.475×0.30mm | **1.20×0.30mm** |
| 相对两排中心距离 | 8.325mm | **8.50mm** |
| 焊盘最外沿跨度 | 9.80mm | **9.70mm** |
| 焊盘最内沿间距 | 6.85mm | **7.30mm** |
| 中央散热焊盘 | 无 | 无 |

前版使用通用 IPC 焊盘，A2 改为 ST 图42的推荐尺寸。图中的 9mm 是芯片引脚外跨，9.70mm 是推荐铜焊盘外跨，两者不是同一个尺寸。

在顶视图中，1～12 脚沿左侧向下，13～24 沿下侧向右，25～36 沿右侧向上，37～48 沿上侧向左。编号与 DS14927 图5一致；图42只是旋转了视图，脚号不需要镜像。

## 24MHz 外部晶振

C562 的 ROM USB DFU 不要求外部晶振。板上的 24MHz HSE 供应用程序使用；ROM DFU 仍按 AN2606 第11章表23使用内部时钟。

| 器件 | 参数 / 连接 |
| --- | --- |
| Y401 | Abracon **ABM8-24.000MHZ-10-D2Y-T**；24MHz、CL=10pF、基频、−40～85℃、频差±20ppm、稳定度±30ppm |
| U401-5 | PH0-OSC_IN，接 Y401-1 与 C408 |
| U401-6 | PH1-OSC_OUT，接 Y401-3 与 C407 |
| Y401-2 / 4 | 外壳接 GND |
| C407 / C408 | 初值 **12pF、C0G、0603**，建议±0.5pF、≥25V |

晶振依据 [Abracon ABM8 2020-07-29 数据手册](reference/Abracon_ABM8_Rev20200729.pdf) 选型：24MHz 时 ESR≤50Ω，C0≤3pF，最大驱动功率100µW。负载电容按 `CL=C407×C408/(C407+C408)+Cstray` 估算，12pF / 12pF 配合约4pF总杂散时得到10pF；4pF是设计估计，最终数值需在实际 PCB 上确认。

按最坏 ESR 与 C0 计算，晶体临界跨导约为 `4×50×(2π×24MHz)²×(3pF+10pF)² = 0.769mA/V`，低于 DS14927 表35给出的 1.5mA/V 最大允许值。冷启动、温度范围、频偏和驱动功率仍需实测；需要时调整负载电容，或在下一版重新预留串联电阻。芯片内置反馈电阻，不另加 1MΩ。

Y401 使用按厂商第2页推荐图制作的 `SSD:Abracon_ABM8_3.2x2.5mm` 封装：四个 1.30×1.05mm 焊盘，中心距 2.30×1.75mm，1 / 3 为晶体端，2 / 4 为外壳地。同尺寸的四脚有源振荡器不能直接替代。

固件需要启用 HSE 晶体模式，等待时钟就绪后再切换系统时钟。安装晶振不会自动改变时钟寄存器。LSE 32.768kHz 未安装，PC13 按键相关的 LSE 勘误仍按迁移记录处理。

## 圆屏焊盘

DS201 的16个铜焊盘从 **2.0mm 改为1.8mm**，1脚仍以方形识别，其余为圆形。钻孔维持1.0mm，标称单边焊环为0.40mm；中心针距2.54mm、两排间距35.08mm和编号均保持不变。

原屏幕资料未给出可确认的针径标称值，所以这次只减小铜焊盘。实际插装间隙仍需拿屏幕核对，见更新后的 [圆屏 1:1 对位图](../review/display_footprint_1to1.pdf)。

## 验证与打开方式

当前原理图和 PCB 各有 59 个器件，其中 23 个电阻、19 个电容，阻容封装均为 0603。PCB 已有板框和走线。`review/` 中的 ERC、网表和 DRC 文件来自删除 R401、J102 之前的检查点，当前版本需要重新生成检查报告。

修改前备份见 [before_hse_footprint_revision.zip](../review/before_hse_footprint_revision.zip)。若 KiCad 仍显示旧封装，关闭相关窗口后重新打开工程；重载前先处理尚未保存的本地改动。
