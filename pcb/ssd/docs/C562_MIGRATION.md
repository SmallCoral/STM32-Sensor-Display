# STM32C562CET6 迁移记录（A2）

24MHz 外部晶振、ST 示例焊盘和圆屏焊盘尺寸记录在 [A2 晶振与封装修订](HSE_FOOTPRINT_A2.md)。

## 迁移内容

主控从 STM32C531CBT6 改为 STM32C562CET6。两者在本项目涉及的 LQFP48 引脚位置相同，迁移时仍按 C562 的引脚图、复用表、供电说明和 Bootloader 文档重新核对。

最小系统页加入 U401 和 C401～C406，电源、显示和传感器电路继续放在各自子页。阻容统一为 0603。BOOT / RESET 网络沿用原设计；PA13 / PA14 保留 SWD 功能，但当前 PCB 没有专用调试连接器。

## 新增器件及布局要求

| 位号 | 参数 / 封装 | 最终布局位置 |
| --- | --- | --- |
| U401 | STM32C562CET6；LQFP48，7×7mm，P0.5mm | 参考电压、SWD 与供电布局共同确定；PA11/PA12 当前空接 |
| C401 | 100nF；0603 | 靠近 U401-24，回地至相邻地平面 |
| C402 | 100nF；0603 | 靠近 U401-36 |
| C403 | 100nF；0603 | 靠近 U401-48 |
| C404 | 4.7µF / 10V；0603 | MCU 的 3.3V 电源入口附近 |
| C405 | 2.2µF / ≥10V；0603，低 ESR | 紧靠 U401-22；VCAP 到电容及回地路径尽量短 |
| C406 | 100nF；0603 | 靠近 U401-9 与 U401-8，避免 LED 扫描电流经过参考地回路 |

VCAP 是内核稳压输出，不是 3.3V 电源。DS14927 要求 C405 的额定电压至少 10V、3MHz 时 ESR＜20mΩ，选型时还要检查直流偏压后的容量和阻抗曲线；0603、2.2µF 只是基本规格。

本版的 VREF+ 与 NTC 分压供电同为 3.3V，维持比率测量关系。C406 直接跨接参考正负端。HSE 已在 A2 接入24MHz晶振，LSE 引脚标记空接；当前 6P Type-C 不含 D+/D−，PA11/PA12 标记空接，下载和调试使用 J-Link SWD。

## 对当前方案有影响的勘误

- **PC13 与 LSE**：ES0661 §2.2.2 说明 LQFP 封装的 PC13 跳变可能干扰 LSE 晶振。本版没有 LSE 晶振，因此保留 PC13 用户按键。以后增加 LSE 时，应迁移按键引脚或采用不受影响的外部时钟方案，并重新审查连接。
- **LSE 驱动档位**：§2.2.4 禁止使用 LSE 低驱动模式；后续增加 RTC 晶振时一并处理。
- **USB 接收缓冲区**：§2.12.1 的限制仅在未来重新接出 USB 数据时适用。当前硬件的 PA11/PA12 空接，不启用 USB 数据功能。
- ADC 使用单 ADC 的常规温度采样方案。若后续启用双 ADC 或注入转换，需要额外审阅 §2.3。

项目当前不使用 FDCAN，PB6 分配给 I2C1_SCL。以后增加 FDCAN 时，需要重新规划复用引脚并加入外部收发器。

## 当前状态

A2 原理图和 PCB 曾各包含 59 个器件。当前 A3 原理图及 BOM 因宽压双路 DCDC、新增 J102、J101 改为 6P 仅供电并删除 D101，共为 68 个器件；PCB 仍停留在 A2 的 59 个封装。R401 已从现行设计中删除；晶振直接连接 PH0 / PH1。J102 按 1=VREF/+3V3、2=SWDIO、3=SWCLK、4=GND 接出调试信号，不含 NRST。

PCB 已有板框和 A2 走线，但旧的 `review/` 检查报告早于这次修改。同步 A3 DCDC 与 J101/J102、重新布局布线后需要重新运行 ERC / DRC。J101 四个外侧椭圆屏蔽壳槽孔到铜间距、屏幕孔径和接插件配套仍按设计说明逐项确认，最终结论以制板工艺审核和样机测试为准。
