# STM32C562CET6 迁移核对 · A2

最新修订已增加24MHz外部晶振、采用ST示例焊盘并缩小圆屏焊盘，详见 [A2 晶振与封装修订](HSE_FOOTPRINT_A2.md)。

## 本次改动

主控从 STM32C531CBT6 改为 **STM32C562CET6**。两者在本工程用到的 LQFP48 引脚位置相同，但本版仍重新逐项核对了 C562 的官方引脚图、复用表、供电和 Bootloader 资料。

原最小系统页只有说明，本次实际加入 U401 和 C401～C406；电源、显示、传感器页继续独立。所有电阻、电容为 0603。原有 BOOT / RESET 网络及 SWD 接口复用，没有重复添加第二套上拉、下拉或复位电容。

## 新增器件及布局要求

| 位号 | 参数 / 封装 | 最终布局位置 |
| --- | --- | --- |
| U401 | STM32C562CET6；LQFP48，7×7mm，P0.5mm | USB 差分对、参考电压及供电布局共同确定 |
| C401 | 100nF；0603 | 靠近 U401-24，回地至相邻地平面 |
| C402 | 100nF；0603 | 靠近 U401-36 |
| C403 | 100nF；0603 | 靠近 U401-48 |
| C404 | 4.7µF / 10V；0603 | MCU 的 3.3V 电源入口附近 |
| C405 | 2.2µF / ≥10V；0603，低 ESR | 紧靠 U401-22；VCAP 到电容及回地路径尽量短 |
| C406 | 100nF；0603 | 靠近 U401-9 与 U401-8，避免 LED 扫描电流经过参考地回路 |

VCAP 为内核稳压输出，实际电压处于内核电源范围，**不是 3.3V 电源**。额定电压至少 10V、3MHz 时 ESR＜20mΩ 是 DS14927 对 C405 的独立要求；采购时应检查指定型号的容量偏压特性与阻抗曲线。不能只凭“0603、2.2µF”就认为任意型号都满足要求。

本版的 VREF+ 与 NTC 分压供电同为 3.3V，维持比率测量关系。C406 直接跨接参考正负端。HSE 已在 A2 接入24MHz晶振，LSE 引脚标记空接；ROM DFU 使用内部 HSI 和 CRS。

## 对当前方案有影响的勘误

- **PC13 与 LSE**：ES0661 §2.2.2 说明 LQFP 封装的 PC13 跳变可能干扰 LSE 晶振。本版没有 LSE 晶振，因此保留 PC13 用户按键。以后增加 LSE 时，应迁移按键引脚或采用不受影响的外部时钟方案，并重新审查连接。
- **LSE 驱动档位**：§2.2.4 禁止使用 LSE 低驱动模式；后续增加 RTC 晶振时一并处理。
- **USB 接收缓冲区**：§2.12.1 指出 OUT 传输的 CTR 中断可能早于最后一次 USB SRAM 更新；应用固件在全速模式访问接收 SRAM 前需按勘误确保 800ns 延迟（低速为 6.4µs）。这是后续固件约束，不通过外加串联电阻解决，也不表示可以修改出厂 ROM。
- ADC 使用单 ADC 的常规温度采样方案。若后续启用双 ADC 或注入转换，需要额外审阅 §2.3。

资料包没有要求本项目启用 FDCAN，本版继续使用 PB6 作为 I2C1_SCL。以后若增加 FDCAN，需要重新规划复用引脚并加入外部收发器。

## 已完成与后续边界

原理图、符号、61 个器件的封装绑定和 PCB 网络已同步。A2 保留原先57个器件的坐标，新增4个晶振配套器件按功能暂放；电容虽然已经在原理图中正确连接，最终 PCB 仍需落实就近去耦、地回路和 USB 阻抗。

未绘制板框或布线。原 USB-C 封装的孔到铜间距问题、显示屏的暂定孔径和接插件配套仍按原设计说明处理。ERC 通过不替代整板 DRC、制板工艺审核或硬件实测。
