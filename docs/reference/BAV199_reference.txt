# Low-leakage double diode 

## 1 April 2023 Product data sheet 

# 1. General description 

Epitaxial, medium-speed switching, double diode in a small SOT23 Surface-Mounted Device (SMD) plastic package. The diodes are connected in series. 

# 2. Features and benefits 

• Plastic SMD package • Low leakage current: typ. 3 pA • Switching time: typ. 0.8 us • Continuous reverse voltage: max. 75 V • Repetitive peak reverse voltage: max. 85 V • Repetitive peak forward current: max. 500 mA. 

# 3. Applications 

• Low-leakage current applications in surface mounted circuits.
