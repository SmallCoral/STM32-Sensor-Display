# 产品固件验证记录

验证日期：2026-10-06。目标板：STM32C562CET6，PCB `pcb/ssd/ssd.kicad_pcb`。

## 工具与下载来源

- SEGGER 官方 J-Link Windows x64 安装包，V9.82；安装前通过 Windows Authenticode 验证，签名主体为 SEGGER Microcontroller GmbH。
- J-Link 驱动安装后设备状态正常，通过 SWD 连接 STM32C562CE；实测 VTref 约 3.30V。
- Arm 官方 GNU Toolchain 14.3.Rel1，GCC 14.3.1；xPack GNU Make 4.4.1。
- 本机计算测试使用 TinyCC 0.9.27，下载归档 SHA256 为 `34a721949a2583fdff725312da092fa0f5f1f284b702e6f811c6954714faabb2`，与公开发行包校验值一致。
- 使用 ST 现有的同一固定提交 `a6288ffbf8824171323b8a7ac2214b70de54b3d8` 补入 ADC、EXTI、TIM 和 IWDG LL 头文件，未替换既有 CMSIS 或时钟驱动版本。

## 已完成

1. ARM 完整编译通过，应用 C 编译使用 `-Wall -Wextra -Werror`；Flash 占用 7720 字节，RAM（含预留堆栈）1784 字节。新版本工具链链接 nosys 时对未实现的文件 IO 存根给出提示；应用不调用这些接口。
2. 电脑端计算与显示测试通过：厂商阻温表基准点、整个有效 ADC 区间温度单调性、故障消抖/恢复、告警滞回、℃/℉、流量和累计量、计数器回绕、屏幕段码及显示溢出。
3. 烧录前保存原 Flash 镜像；新版固件通过 J-Link 编程与 Flash 校验。
4. 板上真实 NTC 采样有效，先后读取到约 31.4℃、25.3℃ 等实际温度。ADC 错误数、显示通信错误数均为 0，显示每 200ms 持续刷新。
5. 用户确认温度显示及 USER 按键的 ℃/℉ 切换正常。
6. 板上流量处理测试：核对 PCB 后，临时将 EXTI1 映射到空接的 PB1，使用调试器产生 20 个真实 GPIO 上升沿。20 个脉冲全部计入，未拒绝脉冲；累计值为 30mL（20×1000/660 取整）。实测平均周期 88351µs，对应 1029mL/min；停止脉冲后流量归零。测试结束复位 MCU，确认 EXTI1 恢复 PA1，测试累计量清零。这项测试验证中断、计时、换算和停流逻辑，不代表水路实测或传感器精度标定。
7. 最终运行快照显示连续运行约 9 分钟，ADC/显示在线、错误数均为 0；相隔 2.5 秒的快照中运行计时和显示刷新数正常递增，NTC 读数约 22.7℃。无通水时流量、脉冲和累计量保持 0，EXTI1 映射确认为 PA1。
